# Counter_BS

Aplikacja mobilna/desktopowa w .NET MAUI do zarządzania wieloma licznikami. Projekt szkolny.

## Funkcje

- Dodawanie liczników z własną nazwą
- Ustawianie wartości początkowej (tylko przy tworzeniu licznika)
- Zwiększanie i zmniejszanie wartości przyciskami + i -
- Usuwanie liczników (z potwierdzeniem)
- Auto-zapis po każdej zmianie wartości
- Wczytywanie zapisanych liczników przy starcie aplikacji
